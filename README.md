# Personal budget app

A basic app that lets you plan your budget by adding expenses

Live preview: [link](https://ignasc.github.io/personal-budget-app/)

## Features

- Shows total, used and remaining budget
- Expense summary breakdown into 4 categories
- Shows a list of expenses
- Warning indicator when close to budget limit
- Warning indicator when over the budget

## Tech stack

- HTML
- CSS
- React

## Learning experience

- Practice using react framework.
- Practice using react components.
